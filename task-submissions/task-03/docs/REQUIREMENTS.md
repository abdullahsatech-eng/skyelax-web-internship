# Requirements

## Source note

Sources available: the SKYELAX portal description of Task 03, the Task 3 master brief, and the mentor feedback on Task 1 ("improve UI"). The four official specification documents (Requirements & Design, Foundation, Design System, Design Tokens) were **not** available. Items are tagged *Portal* or *Brief*.

## Objectives
- Build a complete multi-page website for a fictional business (Portal).
- Present company information, services, projects and contact options in a consistent design system (Portal).
- Improve visual quality of the user interface (mentor feedback).

## Users
Small businesses, startups and growing companies (Brief); the internship mentor as evaluator (assumption).

## Constraints
HTML5, CSS3 and vanilla JavaScript only; no backend or build tools.

## Assumptions
Colours, typography, spacing, page copy and project concepts are original developer choices.

## Acceptance criteria
A requirement is accepted when its test in `TRACEABILITY.md` has a recorded Pass.
