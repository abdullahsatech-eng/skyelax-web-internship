# QA Checklist

Tick items only after you have verified them yourself.

## Page completeness
- [ ] Home, About, Services, Projects, Contact open and show full content
- [ ] Each page has a unique title and one `h1`

## Links
- [ ] Header and footer links work on every page
- [ ] Service anchors (`services.html#...`) scroll to the right section
- [ ] No 404 for CSS, JS, SVG files

## Styling consistency
- [ ] Header, dark footer, buttons and cards look identical across pages
- [ ] Gradient header band and accent colours appear on every page
- [ ] No unstyled elements

## JavaScript
- [ ] Menu opens and closes; Escape and outside click close it
- [ ] No console errors on any page

## Form
- [ ] Empty submit shows errors and focuses the first invalid field
- [ ] Invalid email and short message are rejected
- [ ] Valid submit shows the honest demo message

## Responsive (320, 375, 390, 600, 768, 900, 1024, 1366, 1920px)
- [ ] No horizontal scrolling
- [ ] No overlapping or clipped text
- [ ] Touch targets are comfortable

## Accessibility
- [ ] Skip link works with keyboard
- [ ] Focus is always visible
- [ ] Tab order is logical
- [ ] 200% zoom remains usable
- [ ] Contrast checked with a tool

## Browser compatibility
- [ ] Chrome  [ ] Edge  [ ] Firefox  [ ] Mobile browser

## Regression
- [ ] Task 1 and Task 2 folders are unchanged

## Deployment
- [ ] GitHub Pages URL loads all five pages
- [ ] Relative paths work from the published subpath
