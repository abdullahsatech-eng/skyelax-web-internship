01 DATABASE MANAGEMENT SYSTEMS

Automated Library Management System

A database-driven library management system reconstructed from surviving academic project documentation using Oracle SQL and PL/SQL.

The documented system manages books, authors, categories, members, borrowing and returns, reservations, and fines. The database design contains eight related tables and was normalized to Third Normal Form.
