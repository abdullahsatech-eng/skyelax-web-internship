# Task 01 — Responsive Personal Portfolio Website

## Objective

Build a responsive personal portfolio website using HTML, CSS, and JavaScript as the first task of the SKYELAX Web Development Internship.

## Requirements

The portfolio must include:

* Navigation bar
* Hero/introduction section
* About section
* Skills section
* At least 3 projects
* Education and/or experience section
* Contact section
* Working navigation links
* Clear spacing and visual hierarchy
* Responsive layout for desktop, tablet, and mobile
* Functional interactive elements where appropriate
* Deployment of the completed website

## Technology

* HTML5
* CSS3
* JavaScript

## Task Status

**Status:** In Progress
