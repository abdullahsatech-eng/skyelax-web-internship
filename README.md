### Task 06 — FixFlow

**Status:** ✅ Completed

**Project:** FixFlow — Service Request Management Platform

FixFlow is a full-stack application developed for Task 06: *Develop a REST API and Connect It with the Frontend*.

It connects a React and TypeScript frontend to a Node.js and Express REST API, with MongoDB Atlas for persistent storage. Users can create, view, update, search, filter, and delete service requests.

**Key Features**
- RESTful GET, POST, PUT, and DELETE endpoints.
- Structured JSON responses and appropriate HTTP status codes.
- Server-side input validation and centralized error handling.
- Frontend integration for displaying and managing API data.
- Request search, filtering, pagination, and status summaries.
- Loading, empty, success, and error states.
- Responsive layouts and accessible interface controls.
- Automated frontend and backend tests.
- Importable Postman collection and API documentation.

**Technology Stack:** React, TypeScript, Vite, Node.js, Express, Mongoose, MongoDB Atlas, Zod, Vitest, Supertest, and React Testing Library.
