### Task 06 — REST API + Frontend Integration

**Status:** Completed

**Project:** FixFlow

FixFlow is a full-stack Service Request Management Platform built to demonstrate REST API development and frontend integration. The React and TypeScript client communicates with a Node.js and Express API, while MongoDB Atlas stores service-request data.

The project demonstrates HTTP methods, structured JSON responses, status codes, server-side validation, error handling, database persistence, frontend API communication, and automated testing.

**Project Objectives**

- Connect a frontend application to a REST API.
- Support service-request CRUD operations.
- Validate incoming data and return understandable errors.
- Persist service requests in MongoDB Atlas.
- Display API data and operation feedback in the frontend.
- Verify API behavior and frontend functionality through testing.

**Main Features**

- Create service requests
- View service requests
- Update service requests
- Delete service requests
- Search and filter service requests
- Pagination for service-request lists
- REST endpoints using GET, POST, PUT, and DELETE
- Structured JSON responses
- Appropriate HTTP status codes
- Server-side input validation
- Centralized API error handling
- MongoDB Atlas persistence
- Frontend loading, empty, success, and error states
- Responsive frontend interface
- Automated backend and frontend tests
- Postman API collection
- Technical documentation

**Technology Stack**

| Technology | Purpose |
|---|---|
| React | Component-based frontend interface |
| TypeScript | Type safety and maintainable code |
| Vite | Frontend development and production build |
| Node.js | Server-side JavaScript runtime |
| Express | REST API routing and middleware |
| MongoDB Atlas | Hosted document database |
| Mongoose | MongoDB object modeling |
| Zod | Input validation |
| Vitest | Automated testing |
| Supertest | HTTP API testing |
| React Testing Library | Frontend component testing |
| Postman | Manual API request verification |

**Testing and Verification**

The project was checked with frontend production build, backend type checking and build, automated backend tests, and automated frontend tests.

The recorded backend result was 73 passing tests and 4 skipped tests; the frontend result was 25 passing tests. The skipped tests depend on MongoDB integration-test configuration and should not be described as passing.

The MongoDB Atlas connection and database persistence were verified locally. A Postman collection is included for API testing; this README does not claim that the collection has been run unless separately verified.

**Scope and Limitations**

FixFlow has been verified locally. This README does not claim a public deployment or live demo URL. Deployment can be addressed if required by a later official internship task.
